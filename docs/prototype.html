The flow

Where the palette comes from

The craft standard says to write with contrast and asymmetry — warm on one side of the face, cool on the other. The interface is built from the same two temperatures against a night ground: ember for what's active and warm, glacier for what's safe and cool.

Ember marks progress and intent. Glacier marks safety and continuity — the returning safe place, the exit to breathing. They never do each other's job.

The page follows your system theme. The device screen never does. The app is dark-only — not a preference. A product about reducing screen time, used mostly at night and in bed, has no business having a light mode.

Rules the interface follows

No loading state

Anywhere. The cached grounding intro plays while the script generates and beats synthesize in parallel. If the user ever sees a spinner, the architecture has failed.

Interface is for selection

Once audio starts the screen is dark and stays dark. Controls exist, but you have to ask for them, and they leave on their own.

The exit is always one tap

No confirmation, no "are you sure." Cached audio, so it works even when generation doesn't.

Never invent the safe place

The user describes it. The system only elaborates within what they gave, and adds exactly one new detail per visit. It never contradicts an established one.

Words are the product

Narration is set in the serif at a readable size even though almost nobody will read it. The one screen where type is decoration is the one where it matters most.

Copy never congratulates

No praise, no encouragement, no "great job." The voice notices things. It does not have opinions about your consistency.

Deliberately absent

  • streaks
  • badges
  • daily goals
  • progress scores
  • push reminders
  • social feed
  • session count
  • "you're on a roll"
  • category browsing
  • star ratings
  • light mode
  • a spinner
